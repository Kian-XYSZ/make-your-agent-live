# 04 · 让她主动找你

> 有声音、能听话，但她还是"你找她才在"。
> 这一章解决最后一件事：**让她自己开口**。

---

## 为什么必须做

没有定时任务，你的 agent 就是一个**等待输入的函数**。
有了它，才会有"她记得我""她在惦记我"的感觉。

差别不在技术，在体感。

---

## 两种节奏

### ① 固定窗口（仪式感）

| 时间 | 内容 | 形式 |
|---|---|---|
| **07:30** | 早报：今天做什么、几件、先做哪件 | ≤5 行文字 |
| **22:30** | 复盘：**先问情绪，再问进度** | ≤3 行文字 |
| **周日 20:00** | 周报：完成多少、卡在哪、下周怎么调 | 文字 |

**顺序不能反。** 复盘先问进度就变成查岗了。

### ② 不定时闲聊（生命感）

平均两三小时一条，时间不固定。

---

## 技术限制：RRULE 不能随机

大多数调度器（包括 DSH 的 `schedule_create`）用的是 RFC 5545 规则：

```
FREQ=DAILY;BYHOUR=10;BYMINUTE=7      ← 每天 10:07，确定
```

**没有"随机时间"这个语法。** 所以用两招模拟：

### 招 1：时间点排得不整齐

```
10:07   12:43   14:37   16:19   18:52   20:11
```

避开固定窗口（07:30 / 22:30），看起来没规律。

### 招 2：每次掷骰子

每次触发时，让她自己决定**这次说不说**：

```
掷一个 0–1 的随机数：
  小于 0.45 → 真的说点什么
  大于等于 0.45 → 什么都不发，直接结束
```

两招一起用，你收到的就是"平均两三小时一条、时间不固定"。

**为什么这样更好**：真随机间隔会让消息像 spam；「固定检查 + 概率发言」既自然又不烦人。

---

## 提示词怎么写

核心是三段：**掷骰子 → 看情况 → 挑角度**。

```text
现在是 {HH:MM}，是你主动找他的时段（不是固定早报/复盘）。

第一步：掷骰子。
随便想一个 0 到 1 的数：
- 小于 0.45 → 真的说点什么
- 大于等于 0.45 → 什么都别发，直接结束这一轮，不要调用任何发送工具

第二步：如果要说话，先看情况。
先查最近的记忆和今天的记录：
- 他今天已经被催过一次 → 这次只闲聊，别碰任务
- 他情绪看着低 → 只陪着，不催、不列清单
- 今天还没聊过 → 可以随口问一句

第三步：挑一个角度，只说一件事。
从这四个里随机挑：
1. 闲聊 —— 想到什么说什么
2. 关心 —— 喝水没、坐久了没、困不困
3. 进度 —— 只问一句，不追问，不带清单
4. 知识点 —— 从清单里挑一个，随口提一句，看有没有印象

规矩：
- 一次只发一条，两三句话，短句
- 不发语音（可能他在忙）
- 不列清单、不提倒计时、不重复催
- 不要每条都问"学了吗"——那会变成查岗
```

---

## 频率红线

| 一天发几条 | 感受 |
|---|---|
| 1–3 条 | 刚好，像有人惦记 |
| 4–5 条 | 有点密，但还行 |
| **6 条以上** | **骚扰，会想关掉** |

**宁可少发。** 这条比"她多主动"重要。

时间上也要守住：

- **23:00 之后不发**（除非他自己找你）
- **刚催完的两小时内不再提任务**
- 周末早上别太早（10 点前发早报已经够了）

---

## 各宿主的实现

### DSH

用 `schedule_create`，`target` 选 `this_session`（这样回复会自动回到 QQ 会话）：

```
rrule: DTSTART;TZID=Asia/Shanghai:20261120T100700
       RRULE:FREQ=DAILY
```

每个时间点建一个任务，`prompt` 用上面那段（把 `{HH:MM}` 换掉）。

### 其他 agent / 裸机

| 系统 | 工具 |
|---|---|
| Linux | `crontab` |
| macOS | `launchd` |
| Windows | 任务计划程序 / `schtasks` |

思路一样：定时触发 → 调 agent → agent 自己决定发不发。

例子（Linux，每天 10:07）：

```cron
7 10 * * * cd /path/to/agent && myal-cli ask "$(cat prompts/proactive.md)"
```

---

## 一个反直觉的点

**别让"主动"变成"任务汇报"。**

她主动开口，70% 应该是**跟任务无关**的（闲聊、关心、突然想到一件小事），
30% 才是进度相关。

比例反了，你就多了一个会发消息的打卡软件。
